# 🌐 网络工具与节点选择入门指南

> 一个从**新手视角**整理的网络工具、节点、线路与相关概念的中文入门资料库。

刚开始接触网络代理工具时，你可能会遇到很多看起来很专业的词：

`Clash` · `节点` · `订阅` · `IP` · `BGP` · `CN2` · `IPLC` · `IEPL` · `原生 IP` · `中转` · `直连`

问题是：

> **这些东西到底是什么？它们之间有什么关系？我应该先了解哪个？**

这个项目就是为了解决这个问题。

我会尽量站在**“刚接触这些东西的新手”**角度，用比较容易理解的方式，把这些概念拆开说明。

---

## 📖 这个项目介绍什么？

目前主要分为几个方向：

### 1. 🧩 基础概念

帮助完全没有网络基础的读者先理解：

- 什么是代理
- 什么是客户端
- 什么是节点
- 什么是订阅
- 什么是协议
- 什么是 IP
- 什么是延迟
- 什么是丢包
- 什么是线路

如果你看到 `Clash`、`节点`、`订阅` 这些词完全不知道是什么意思，**建议从这里开始。**

---

### 2. 💻 客户端工具

介绍常见的网络工具以及它们适合什么平台，例如：

- Clash Verge Rev
- Shadowrocket
- Stash
- Surge
- v2rayN
- v2rayNG
- sing-box
- Hiddify

文章不会只告诉你“这个软件是什么”，也会尽量说明：

> **什么人适合使用？应该去哪里下载？**

涉及具体软件时，会尽可能提供对应的**官方网站、官方 GitHub 或官方应用商店页面**，方便读者自行查看。

---

### 3. 🌐 节点与线路

这一部分主要解释：

- 直连
- 中转
- BGP
- CN2
- IPLC
- IEPL
- 专线
- 不同线路之间的大致区别

这里不会简单告诉你：

> “某某线路一定最好。”

因为实际网络体验会受到很多因素影响。

更重要的是理解：

> **线路是什么，以及它为什么会影响网络体验。**

---

### 4. 📍 IP 与网络环境

帮助新手理解一些经常出现的词：

- IP
- 原生 IP
- 数据中心 IP
- 住宅 IP
- 独享 IP
- 共享 IP
- IP 地区
- IP 稳定性

这些概念经常会出现在 AI、流媒体、网站访问以及其他网络服务的使用场景中。

---

### 5. 🎮 不同使用场景

不同需求，对节点的要求并不一样。

例如：

| 使用场景 | 主要关注 |
|---|---|
| 🌐 普通网页 | 稳定性、速度 |
| 🤖 AI 服务 | IP、地区、稳定性 |
| 🎬 流媒体 | 地区、IP 类型、服务支持 |
| 🎮 游戏 | 延迟、丢包、延迟稳定性 |
| 💻 网络开发 | 协议、路由、调试能力 |

所以：

> **并不存在一个节点可以适合所有人。**

## 🧭 新手阅读路线

如果你第一次来到这个项目，不建议一上来就研究 `IPLC`、`IEPL` 或 `CN2`。

推荐按照这个顺序：

```text
① 什么是代理
        ↓
② 什么是客户端
        ↓
③ 什么是订阅
        ↓
④ 什么是节点
        ↓
⑤ 什么是 IP
        ↓
⑥ 什么是线路
        ↓
⑦ 什么是延迟 / 丢包
        ↓
⑧ 直连 / 中转 / 专线
        ↓
⑨ BGP / CN2 / IPLC / IEPL
        ↓
⑩ 根据自己的需求选择
```

这样会比直接背专业术语容易很多。

## ⚠️ 关于本文档

这不是一份“万能配置教程”，也不是某个服务商的宣传页面。

这里更希望解决的是：

> **“我刚开始接触这些东西，到底应该先懂什么？”**

因此文章会尽量：

- 少使用没有解释的专业术语
- 避免把复杂概念简单化成绝对结论
- 尽量区分“理论上的线路”和“实际使用体验”
- 对容易产生误解的营销术语进行说明
- 提供官方资料方便进一步阅读

如果某个地方写得不准确，也欢迎通过 **Issue** 提出。
